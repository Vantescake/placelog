# PlaceLog

Лабораторна робота №3 з дисципліни «Кросплатформне програмування» (НУ «Львівська політехніка», ПЗ-32, Родінчук А. С.).

Варіант 24: каталог закладів і відгуків. Реалізовано базову структуру застосунку на Flutter та екрани за макетами Figma без бізнес-логіки:

- вхід, реєстрація, відновлення пароля;
- головний екран зі статистикою та нещодавно відвіданими закладами;
- профіль користувача та зміна пароля.

## Запуск

```bash
flutter pub get
flutter run -d chrome
```

Застосунок відображається лише в мобільній ширині (до 430 px).

## Структура

```
lib/
├── main.dart          точка входу
├── core/              тема, маршрути, тестові дані, спільні віджети (core/widgets)
└── features/          екрани: auth, home, profile, main (нижня навігація)
```

## Перевірка

```bash
flutter analyze
flutter test
```
